# Документы Nexon EDO — вселенная CityOS

Пакет содержит готовые шаблоны документов и заполненные демонстрационные экземпляры Nexon Labs. Имена пациентов, номера записей, адреса, специалисты и учреждения вымышлены и предназначены для проекта.

Шаблоны можно использовать в макетах, демо, тестовых данных и прогонах NexonEDO. Поля в фигурных скобках заменяются данными из Registry или вводом уполномоченного сотрудника. Подписываемая версия фиксируется неизменяемым снимком; исправление документа создаёт новую версию.

## Общие метаданные

Каждый документ в EDO дополнительно получает системные поля:

- `documentId`, `documentType`, `version`, `status`;
- `patientId`, `appointmentId`, `clinicId`;
- `authorId`, список согласующих и подписантов;
- хэш содержимого подписанной версии, подписи и ссылки на сертификаты;
- даты создания, отправки на согласование, подписания и архивирования.

Эти поля и события процесса хранятся в структурированных метаданных и аудите. Системные значения подписи, хэша и сертификата не подставляются в текст документа.
