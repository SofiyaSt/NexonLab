# Рецепт

**Тип:** `PRESCRIPTION`  
**Маршрут:** автор → главный врач/уполномоченный согласующий → подпись  
**Связь с Registry:** пациент и клиника передаются по идентификаторам

## Шаблон

```text
NEXON LABS
ПРОГРАММА «ЗДОРОВЬЕ ГОРОДА» · CITYOS

РЕЦЕПТ

Номер документа: {{documentNumber}}
Дата создания: {{issuedAt}}
Версия: {{version}}

Пациент: {{patientFullName}}
Идентификатор пациента: {{patientId}}
Клиника: {{clinicName}}
Запись на приём: {{appointmentId}}

Назначивший врач: {{prescriberFullName}}
Специальность: {{prescriberSpecialty}}

Назначение:
Наименование: {{productName}}
Форма/концентрация: {{productForm}}
Количество: {{quantity}}
Способ применения: {{directions}}
Срок применения: {{duration}}

Примечание врача:
{{prescriberNote}}

Согласование:
Решение: {{reviewDecision}}
Согласующий: {{reviewerFullName}}
Комментарий: {{reviewComment}}

Подписант: {{signerFullName}}
Сертификат: {{certificateSerial}}
Время подписи: {{signedAt}}
```

## Заполненный экземпляр для демо

```text
NEXON LABS
ПРОГРАММА «ЗДОРОВЬЕ ГОРОДА» · CITYOS

РЕЦЕПТ — ДЕМО-КОНТУР

Номер документа: NX-EDO-DEMO-0003
Дата создания: 2030-04-12
Версия: 1

Пациент: Алексей Тестовый
Идентификатор пациента: patient-demo-001
Клиника: Nexon Central Medical
Запись на приём: appointment-demo-001

Назначивший врач: Елена Демонстрационная
Специальность: терапия

Назначение:
Наименование: DEMO-ITEM-001 (фиктивная позиция каталога)
Форма/концентрация: отсутствует
Количество: 0 (тест согласования, не отпускать)
Способ применения: не задан
Срок применения: не задан

Примечание врача:
Позиция является тестовой заглушкой и не соответствует лекарственному средству.

Согласование:
Решение: approved
Согласующий: Мария Главврач-Демо
Комментарий: Проверен переход статуса и запись решения в аудит.

Подписант: Елена Демонстрационная
Сертификат: NX-DEMO-CERT-0001
Время подписи: 2030-04-12 13:10, Europe/Moscow
```

Демо-позиция нужна только для проверки маршрута согласования и подписи; она не является назначением и не должна попадать в контур отпуска.
