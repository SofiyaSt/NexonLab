# Направление

**Тип:** `REFERRAL`  
**Маршрут:** врач → подпись врача → принимающая клиника  
**Связь с Registry:** создаётся из контекста пациента и приёма

## Шаблон

```text
NEXON LABS
ПРОГРАММА «ЗДОРОВЬЕ ГОРОДА» · CITYOS

НАПРАВЛЕНИЕ

Номер документа: {{documentNumber}}
Дата выдачи: {{issuedAt}}
Действительно до: {{validUntil}}
Версия: {{version}}

Пациент: {{patientFullName}}
Идентификатор пациента: {{patientId}}
Запись-основание: {{appointmentId}}

Кем направлен:
Врач: {{referringDoctor}}
Клиника: {{sourceClinic}}

Куда направлен:
Клиника: {{destinationClinic}}
Код клиники: {{destinationClinicId}}
Специальность/служба: {{destinationService}}

Цель направления:
{{referralPurpose}}

Сопроводительная информация:
{{clinicalSummary}}

Приложенные документы:
{{attachments}}

Подписант: {{signerFullName}}
Сертификат: {{certificateSerial}}
Время подписи: {{signedAt}}
```
